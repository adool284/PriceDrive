PriceDrive
PriceDrive is a pilot project developed to explore the application of machine learning in the automotive market. The objective of this project is to create a regression model capable of estimating the market value of used cars based on technical specifications and usage history.

Project Overview
This project serves as a practical implementation of data science workflows, covering the entire lifecycle from exploratory data analysis and feature engineering to model deployment. It was developed to consolidate skills in statistical programming and machine learning pipeline design.

Technical Implementation
Data Preprocessing & Engineering: The pipeline handles missing values, categorical encoding, and feature creation (e.g., calculating car age and annual mileage) to improve model accuracy.
Model Pipeline: A scikit-learn pipeline is utilized to encapsulate preprocessing and regression, ensuring reproducibility and preventing data leakage.
Web Interface: The model is deployed via Streamlit, providing a functional interface for real-time predictions and market insights.
Prerequisites
To run this project locally, ensure you have Python 3.x installed. The required dependencies are listed in requirements.txt.
